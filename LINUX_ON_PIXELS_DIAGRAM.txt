**Legend:**

- **Host Linux**: The system running geometry_os
- **GeOS VM**: The native Geometry OS virtual machine
- **Pixel Substrate**: The Memory Palace framebuffer (256×256 RGBA)
- **RISC-V Hypervisor**: Full RISC-V emulator in Rust
- **Linux Kernel**: Guest operating system (RV32)
- **Init**: Userspace initialization process
- **VFS Surface**: Files encoded as pixels @ 0x7000_0000

**Key Innovations:**

1. **Pixels ARE Files**: Every file is stored as RGBA pixels in the framebuffer
2. **Visual Persistence**: Files survive reboots without serialization
3. **Cross-Language Interop**: Rust, C, GeOS assembly all read/write the same pixel format
4. **Live Debugging**: See the filesystem as visual patterns in the framebuffer
5. **Autonomous Palace**: The Memory Palace runs autonomously, self-updating from RAM

**Boot Time:** ~1 second from host start to Linux prompt

**Memory Usage:**
- GeOS VM: ~10MB
- RISC-V guest RAM: 512MB (configurable)
- VFS Surface: 256KB (fixed)
- Total: ~522MB typical

**Instructions Executed:** ~10M instructions to boot to shell
